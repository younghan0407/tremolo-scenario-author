# data — AI 에게 전달할 자료를 넣는 폴더

스크립트를 만들 때 AI 가 참고해야 할 자료를 여기에 넣고, 요청할 때 파일 이름을 알려 주세요.

- **TC 워크북**(기능 테스트 케이스 .xlsx) — 프로젝트를 만들 때 `tremolo.cmd project init <솔루션> <버전> --tc "data\<파일>.xlsx" --env <환경>`
  으로 지정하면 프로젝트 폴더(`projects/<솔루션>-<버전>/source/`)로 복사되어 쓰입니다.
- 기획서·화면 설계서·변경 이력, 화면 캡처, 참고 녹화본 등 — TC 만으로 부족한 조건을 확인할 때 AI 가 읽습니다.

이 폴더의 파일은 하네스 배포본에 포함되지 않습니다(이 안내 파일만 포함). 실행에 쓰는 업로드용 파일(이미지·공개 키 등)은
여기가 아니라 Tremolo 의 `data\testfiles\` 에 둡니다.
